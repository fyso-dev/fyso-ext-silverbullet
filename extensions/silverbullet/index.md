# Conocimiento del proyecto

Aquí vive lo que el proyecto sabe. Las personas y los bots leen y escriben las mismas páginas: cada una es un archivo Markdown en `project/wiki/`.

## Cómo se alimenta

1. **Escribe aquí.** Esta página se edita directamente y se guarda sola. Para crear otra, escribe su nombre entre dobles corchetes y haz clic en el enlace.
2. **Pídeselo a un bot.** En el panel, da acceso al bot (Bots → perfil → skill `project-knowledge`) y dile, por ejemplo: «Documenta en la base de conocimiento cómo desplegamos a producción».
3. **Trae lo que ya tienes.** Copia archivos `.md` a `project/wiki/`. Aparecen al instante.

## Por dónde empezar

- [[Decisiones]]: qué se decidió, cuándo y por qué.
- [[Procedimientos]]: cómo se hace cada tarea que se repite.
- [[Referencias]]: datos, enlaces y contactos que se consultan a menudo.

Separa los hechos comprobados de las propuestas y de las preguntas abiertas. No guardes contraseñas ni claves. Los cambios entran en el historial del proyecto con el respaldo (Git).

Puedes reescribir esta página: es tuya y las actualizaciones no la reemplazan.
